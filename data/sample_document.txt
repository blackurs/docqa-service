# docqa-service — пример документа для демонстрации

Внутренний сервис обработки документов компании «Пример».

## Ограничения и таймауты

По умолчанию клиент LLM использует таймаут 20 секунд. Таймаут настраивается
переменной окружения LLM_TIMEOUT_SECONDS. При сетевой ошибке, таймауте, ответе
429 или 5xx сервис выполняет до двух повторных попыток с экспоненциальной
задержкой (LLM_MAX_RETRIES=2, LLM_RETRY_BACKOFF_SECONDS=0.5).

## Кеширование

Результаты успешных ответов кешируются на 300 секунд по умолчанию
(CACHE_TTL_SECONDS). Ключ кеша учитывает текст вопроса, текст документа, модель
и количество фрагментов. Повторный запрос возвращает заголовок X-Cache: HIT и
не обращается к LLM. Ответы, полученные через fallback, в кеш не сохраняются.

## Ограничения входных данных

Минимальная длина вопроса — 3 символа, максимальная — 500 символов
(MIN_QUESTION_CHARS, MAX_QUESTION_CHARS). Максимальный размер документа —
20 000 символов (MAX_CONTEXT_CHARS). Превышение лимитов возвращает HTTP 422 с
кодом validation_error.

## Отказоустойчивость

Если LLM недоступен, а fallback разрешён, сервис возвращает HTTP 200 с
признаком degraded=true и извлекает наиболее релевантные предложения
непосредственно из документа. Если fallback запрещён (allow_fallback=false),
сервис возвращает HTTP 503 с кодом llm_unavailable.
